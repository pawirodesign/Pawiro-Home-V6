# Pawiro Home V6.1

UX improvement build based on Pawiro Home V6.

## What changed
- Stronger Home hierarchy: Needs Attention, What Should I Do Now, Up Next.
- Prominent Ask Pawiro and universal Add action.
- Floating Add button for mobile/desktop.
- Quick Add hub for tasks, shopping, meals, events, workflows and issues.
- Improved household goal presentation.
- More actionable Home command centre.
- Improved attention review with priority explanation entry points.
- Existing V6 workflow, AI knowledge, inventory, household memory, voice and tablet features retained.
- V6 local demo data is migrated automatically when V6.1 opens for the first time.

## Run
Serve this folder over HTTPS for full PWA behaviour. GitHub Pages is suitable.

## Voice
Use Ask Pawiro → Start listening. Example: “Hey Pawiro, start laundry.” A background wake word while the browser/app is closed is not implemented in this PWA prototype.
